# 03. Git і GitHub

**Навіщо:** Claude Code змінює багато файлів за раз. Git дає можливість побачити, що змінилось, і відкотити, якщо щось зламалось. А ще це твоє портфоліо на GitHub.

**Тривалість:** ~1 тиждень

## Уроки
- [ ] Урок 1. Перший репозиторій: init, add, commit, log, .gitignore
- [ ] Урок 2. Перегляд змін і відкат: diff, restore, revert
- [ ] Урок 3. Гілки: branch, switch, merge
- [ ] Урок 4. GitHub: push, pull, приватні репозиторії, README для портфоліо
- [ ] Урок 5. Експорт n8n-workflows у Git (версіонування автоматизацій)
- [ ] Підсумковий проєкт

## Підсумковий проєкт
Репозиторій на GitHub з твоїми скриптами та експортованими n8n-workflows, з нормальним README і без жодного секрету в історії.

## Результат теми
Ти не боїшся, що Claude Code щось зламає, бо будь-яку зміну можна побачити й відкотити.
