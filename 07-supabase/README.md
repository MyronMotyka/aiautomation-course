# 07. Supabase (Postgres у хмарі)

**Навіщо:** готова база даних з API, авторизацією і векторним пошуком для RAG. Для більшості клієнтських проєктів цього достатньо як бекенду.

**Тривалість:** ~1–2 тижні

## Уроки
- [ ] Урок 1. Перший проєкт: таблиці, SQL Editor, автоматичний REST API, ключі
- [ ] Урок 2. Підключення з n8n і Python
- [ ] Урок 3. Row Level Security (RLS): хто що бачить
- [ ] Урок 4. Database functions і triggers: реакція на нові записи
- [ ] Урок 5. pgvector: зберігаємо embeddings для RAG
- [ ] Урок 6. Storage: файли клієнта (PDF, фото)
- [ ] Підсумковий проєкт

## Підсумковий проєкт
База для AI-асистента клієнта: таблиці клієнтів, розмов і повідомлень (пам'ять агента), налаштований RLS, підключення з n8n.

## Результат теми
Ти можеш дати агенту довготривалу пам'ять і зберігати дані клієнта правильно та безпечно.
