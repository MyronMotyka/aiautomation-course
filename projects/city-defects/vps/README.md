# Міські дефекти: версія для VPS

Мешканець відкриває сайт з телефону, і браузер одразу пропонує поділитися локацією. Точка ставиться на карту, адреса підставляється сама. Далі мешканець робить фото, Claude визначає категорію, терміновість і службу, і заявка потрапляє в диспетчерську.

## Що всередині

| Частина | Технологія |
|---|---|
| Бекенд | Python, FastAPI (`app/main.py`) |
| AI | Claude API, розпізнавання фото, відповідь у форматі JSON-схеми (`app/ai.py`) |
| База | SQLite (`data/reports.db`), фото в `data/photos/` |
| Карта | Leaflet + OpenStreetMap (безкоштовно, без ключа) |
| Адреса за координатами | OpenStreetMap Nominatim |
| HTTPS | Caddy, сертифікат Let's Encrypt отримується автоматично |

Сторінки:
- `/` для мешканця: карта, геолокація, фото, AI-аналіз, статус заявки.
- `/dispatch` для диспетчера: карта всіх заявок, фільтри, зміна статусів. Вхід за логіном і паролем.

## Розгортання на VPS (Ubuntu)

Потрібно: VPS з відкритими портами 80 і 443, ключ Claude API ([console.anthropic.com](https://console.anthropic.com)).

**1. Встановіть Docker** (якщо його ще немає):
```bash
curl -fsSL https://get.docker.com | sh
```

**2. Скопіюйте папку `vps` на сервер.** З вашого комп'ютера:
```bash
scp -r projects/city-defects/vps root@ВАШ_IP:/opt/city-defects
```

**3. Налаштуйте `.env`** на сервері:
```bash
cd /opt/city-defects
cp .env.example .env
nano .env
```
- `ANTHROPIC_API_KEY`: ваш ключ.
- `DOMAIN`: ваш домен, якщо він є. Якщо домену немає, візьміть IP з дефісами замість крапок і допишіть `.sslip.io`. Наприклад, для IP `203.0.113.5` це `203-0-113-5.sslip.io`. Це безкоштовний сервіс, який перетворює IP на доменне ім'я, і для нього теж видається HTTPS-сертифікат.
- `DISPATCH_PASSWORD`: довгий пароль для диспетчерської.
- `CONTACT_EMAIL`: ваш email. Цього вимагають правила OpenStreetMap для визначення адреси.

**4. Запустіть:**
```bash
docker compose up -d --build
```
За хвилину сайт працюватиме на `https://ВАШ_ДОМЕН`, а диспетчерська на `https://ВАШ_ДОМЕН/dispatch`.

**Корисні команди:**
```bash
docker compose logs -f app      # логи
docker compose restart app      # перезапуск після зміни .env
docker compose up -d --build    # оновлення після зміни коду
```

## Важливо

- **HTTPS обов'язковий.** Без нього телефон не дасть сайту доступ до геолокації.
- **Вартість.** Кожен аналіз фото коштує кілька центів за тарифами Claude API. Щоб ніхто не «спалив» ваш бюджет, з однієї IP-адреси можна зробити не більше `ANALYZE_PER_HOUR` аналізів на годину (за замовчуванням 20). Також поставте ліміт витрат у Console.
- **Приватність.** Перед збереженням фото перекодовується, тому з нього видаляються EXIF-дані, зокрема GPS і модель телефону. Контакт мешканця бачить лише диспетчер.
- **Резервні копії.** Усі дані лежать у папці `data/`. Регулярно копіюйте її.
- **Місто за замовчуванням.** Карта стартує з Києва. Щоб змінити місто, поміняйте `DEFAULT_CENTER` в `app/static/common.js`.

## Локальний запуск (для розробки)

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt     # Windows; на Linux/Mac: .venv/bin/pip
set ANTHROPIC_API_KEY=...                          # Windows cmd; PowerShell: $env:ANTHROPIC_API_KEY="..."
.venv/Scripts/python -m uvicorn app.main:app --reload
```
Сайт відкриється на http://localhost:8000. Браузери дозволяють геолокацію на `localhost` і без HTTPS.

## Що можна додати далі
