# 00. Python для автоматизації

**Навіщо:** ти вже знаєш Python. Тут тільки те, що потрібно в автоматизації: середовище, API, дані, файли, webhooks. Жодних алгоритмів заради алгоритмів.

**Тривалість:** ~2 тижні (паралельно з темою 01)

## Уроки
- [ ] Урок 1. Робоче середовище: venv, pip, requirements.txt, .env і секрети
- [ ] Урок 2. requests: викликаємо API, заголовки, таймаути, помилки
- [ ] Урок 3. JSON і трансформація даних: dict/list comprehension, валідація (pydantic)
- [ ] Урок 4. Файли клієнта: CSV, Excel (openpyxl/pandas), PDF (витяг тексту)
- [ ] Урок 5. FastAPI: власний webhook-ендпоінт за 20 рядків
- [ ] Урок 6. Логування і обробка помилок: logging, try/except, retry
- [ ] Урок 7. Запуск за розкладом і на сервері: cron, systemd, Docker
- [ ] Підсумковий проєкт
