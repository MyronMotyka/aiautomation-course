# 12. Бізнес: ніша, продажі, ціни, договори

**Навіщо:** технічні навички без клієнтів не дають грошей. Цю тему починай з 6-го тижня, а не після всього іншого.

**Тривалість:** постійно, з 6-го тижня

## Уроки
- [ ] Урок 1. Вибір ніші та ідеального клієнта
- [ ] Урок 2. Як знаходити «болі»: діагностична розмова з бізнесом
- [ ] Урок 3. Рахуємо цінність: години × ставка = скільки клієнт економить
- [ ] Урок 4. Ціноутворення: проєкт + щомісячна підтримка
- [ ] Урок 5. Пошук клієнтів: знайомі, LinkedIn, холодні листи, локальний бізнес
- [ ] Урок 6. Пропозиція (proposal) і ТЗ: що робимо, що НЕ робимо, терміни
- [ ] Урок 7. Договір, доступи, персональні дані і безпека
- [ ] Урок 8. Перший клієнт: як отримати кейс і відгук
- [ ] Підсумковий проєкт

## Підсумковий проєкт
Перший клієнт (навіть за мінімальну ціну) з підписаною пропозицією, виконаним проєктом і відгуком.

## Результат теми
У тебе є відпрацьований процес: знайти клієнта → провести діагностику → продати → здати → взяти на підтримку.
