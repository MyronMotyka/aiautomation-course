# 05. n8n поглиблено

**Навіщо:** n8n — основа більшості твоїх клієнтських проєктів. Різниця між «працює в мене» і «працює в клієнта пів року без мене» — в обробці помилок, структурі та моніторингу.

**Тривалість:** ~2–3 тижні

## Уроки
- [ ] Урок 1. Обробка помилок: Retry, On Error, Error Workflow
- [ ] Урок 2. Робота з даними: items, Code node, Merge, Split, Loop
- [ ] Урок 3. Sub-workflows: розбиваємо великий процес на модулі
- [ ] Урок 4. Credentials і змінні середовища: як не світити ключі клієнта
- [ ] Урок 5. AI Agent node: інструменти, пам'ять, обмеження
- [ ] Урок 6. Webhook-ендпоінти: приймаємо дані з форм і сайтів, відповідаємо
- [ ] Урок 7. Моніторинг і логування: як дізнатися про падіння раніше за клієнта
- [ ] Урок 8. Передача проєкту клієнту: документація, доступи, підтримка
- [ ] Підсумковий проєкт

## Підсумковий проєкт
Workflow «обробка заявки»: webhook з форми → перевірка даних → AI-класифікація → запис у базу → повідомлення в Telegram. Плюс Error Workflow, який сповіщає тебе про будь-яке падіння.

## Результат теми
Твої workflows можна віддавати клієнту в продакшн.
