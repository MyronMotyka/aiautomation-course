# 02. SQL

**Навіщо:** у клієнтів дані лежать у базах: заявки, клієнти, замовлення. Агентам потрібна пам'ять, звітам потрібні вибірки. Без SQL ти залежиш від Google Sheets, а вони ламаються на великих обсягах.

**Тривалість:** ~2–3 тижні (по 30–60 хв на день)

## Уроки
- [ ] Урок 1. Що таке реляційна база. Перша таблиця і SELECT (SQLite через Python)
- [ ] Урок 2. Фільтри та сортування: WHERE, ORDER BY, LIMIT, LIKE
- [ ] Урок 3. Зміна даних: INSERT, UPDATE, DELETE (і чому DELETE без WHERE небезпечний)
- [ ] Урок 4. Зв'язки між таблицями: JOIN
- [ ] Урок 5. Звіти: GROUP BY, COUNT, SUM, AVG
- [ ] Урок 6. Проєктуємо міні-CRM: клієнти, заявки, статуси
- [ ] Урок 7. Індекси та JSONB у Postgres
- [ ] Підсумковий проєкт

## Підсумковий проєкт
База міні-CRM (клієнти → заявки → дзвінки) і 5 SQL-запитів для звіту:
«скільки заявок за тиждень», «конверсія по джерелах», «клієнти без відповіді понад 24 години» тощо.

## Результат теми
Ти можеш спроєктувати таблиці під процес клієнта і написати запит для звіту без підказок.
