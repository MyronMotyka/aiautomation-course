# Урок 1. Що таке реляційна база. Перша таблиця і SELECT

## Мета
Після уроку ти розумієш, як влаштована база даних, створюєш таблицю і дістаєш з неї дані запитом SELECT. Практикуємось у SQLite: вона вбудована в Python, нічого встановлювати не треба.

## Теорія

### 1. Таблиця — це як аркуш Excel, тільки строгіший
- **Таблиця** (`clients`): одна сутність бізнесу.
- **Рядок**: один запис (один клієнт).
- **Колонка**: властивість (ім'я, телефон, місто).
- У кожної колонки є **тип**: число, текст, дата. Записати текст у числове поле не вийде, і це добре, бо дані не псуються.
- **Первинний ключ** (`id`): унікальний номер рядка. За ним інші таблиці посилаються на цей запис.

### 2. Чому не Google Sheets
Sheets підходять для старту, але повільнішають на тисячах рядків, не захищають від дублікатів і неправильних типів, а при одночасному записі з кількох workflows дані можуть загубитися. База даних вирішує все це.

### 3. SELECT — основа основ
```sql
SELECT колонки FROM таблиця;
SELECT * FROM clients;              -- усі колонки
SELECT name, phone FROM clients;    -- тільки потрібні
```

## Приклади

Створи файл `practice/lesson01.py`:
```python
import sqlite3

conn = sqlite3.connect("practice/crm.db")   # файл бази створиться сам
cur = conn.cursor()

cur.execute("""
CREATE TABLE IF NOT EXISTS clients (
    id      INTEGER PRIMARY KEY AUTOINCREMENT,
    name    TEXT NOT NULL,
    phone   TEXT,
    city    TEXT,
    source  TEXT,          -- звідки прийшов: instagram, google, referral
    created DATE DEFAULT CURRENT_DATE
)
""")

cur.executemany(
    "INSERT INTO clients (name, phone, city, source) VALUES (?, ?, ?, ?)",
    [
        ("Олена Коваль", "+380501112233", "Київ", "instagram"),
        ("Андрій Мельник", "+380672223344", "Львів", "google"),
        ("Ірина Шевчук", None, "Київ", "referral"),
    ],
)
conn.commit()

for row in cur.execute("SELECT name, city FROM clients"):
    print(row)

conn.close()
```
Зверни увагу на `?`: дані передаються окремо від запиту. Це захист від **SQL-ін'єкцій**. Ніколи не склеюй SQL з даними користувача через f-string.
