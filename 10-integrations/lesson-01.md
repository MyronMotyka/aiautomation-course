# Урок 1. Telegram-бот через n8n: від BotFather до AI-відповіді

## Мета
Після уроку в тебе працює Telegram-бот, який відповідає з допомогою AI. Це найшвидший спосіб показати клієнту демо.

## Теорія

### 1. Як працює Telegram-бот
1. Бота створюють через **@BotFather** і отримують **токен**. Токен — це повний доступ до бота, зберігай його як пароль.
2. Коли користувач пише боту, Telegram надсилає повідомлення на твій сервер (**webhook**).
3. Твій сервер (n8n) обробляє повідомлення і надсилає відповідь через Bot API.

### 2. Важливе обмеження
Telegram Trigger у n8n використовує webhook. Telegram має достукатися до твого n8n з інтернету через **HTTPS**. Тому:
- n8n Cloud або n8n на VPS з доменом і HTTPS → працює;
- n8n на localhost → не працює без тунелю (пізніше тема 06).

### 3. chat_id
Кожен чат має унікальний `chat_id`. Відповідь надсилається саме на нього. Пізніше за `chat_id` ти зберігатимеш історію розмови в базі.

## Приклади

Workflow:
```
[Telegram Trigger: On message]
      ↓
[AI Agent / Anthropic Chat Model]   ← текст: {{ $json.message.text }}
      ↓
[Telegram: Send Message]            ← Chat ID: {{ $('Telegram Trigger').item.json.message.chat.id }}
                                       Text: відповідь моделі
```

System prompt для AI:
```
Ти помічник автосервісу «Мотор». Відповідай коротко і доброзичливо.
Якщо клієнт хоче записатися, попроси марку авто, проблему і зручний день.
```

## Практика

**Завдання 1.** У Telegram знайди @BotFather → `/newbot` → придумай назву. Збережи токен у Credentials n8n (не в нотатках і не в цьому курсі).

**Завдання 2.** Зроби «ехо-бота»: Telegram Trigger → Telegram Send Message з тим самим текстом. Перевір, що бот відповідає.

**Завдання 3.** Додай між ними AI-модель із system prompt автосервісу. Поговори з ботом 5 повідомленнями.

**Завдання 4.** Бот не пам'ятає попередніх повідомлень. Знайди в n8n, як додати пам'ять (Memory у AI Agent), і підключи її з ключем сесії `chat_id`.

## Контрольні запитання
1. Що таке токен бота і де його зберігати?
2. Чому Telegram Trigger не працює на n8n, запущеному лише на localhost?
3. Навіщо потрібен `chat_id`?
4. Чому пам'ять розмови прив'язують саме до `chat_id`?
5. Який бізнес-процес у малого бізнесу можна закрити таким ботом за 1–2 дні?

<details>
<summary>Відповіді</summary>

1. Ключ повного доступу до бота. Зберігати в Credentials n8n або `.env`, нікому не показувати.
2. Telegram надсилає webhook з інтернету через HTTPS, а localhost ззовні недоступний.
3. Щоб надіслати відповідь у правильний чат.
4. Щоб розмови різних клієнтів не змішувалися.
5. Наприклад: збір заявок на запис, відповіді на часті питання, кваліфікація лідів перед дзвінком менеджера.
