# 04. Claude Code як головний інструмент

**Навіщо:** це твій «розробник у команді». Від того, як ти ставиш задачі й перевіряєш результат, залежить швидкість і якість твоїх проєктів.

**Тривалість:** ~1–2 тижні, далі практика постійно

## Уроки
- [ ] Урок 1. Як ставити задачу: контекст, мета, обмеження, критерій готовності
- [ ] Урок 2. CLAUDE.md: пам'ять проєкту і правила для Claude
- [ ] Урок 3. Plan mode: спершу план, потім код
- [ ] Урок 4. Перевірка роботи: читаємо diff, просимо тести, запускаємо самі
- [ ] Урок 5. MCP: підключаємо до Claude зовнішні інструменти (бази, сервіси)
- [ ] Урок 6. Дебаг разом із Claude: логи, помилки, відтворення проблеми
- [ ] Підсумковий проєкт

## Підсумковий проєкт
Повністю з Claude Code зробити невеликий сервіс на FastAPI, який приймає webhook і записує дані в базу. Вимоги: CLAUDE.md, Git-історія з кількох комітів, і ти можеш пояснити кожен файл.

## Результат теми
Ти отримуєш від Claude робочий код з першої-другої спроби і розумієш, що він зробив.
