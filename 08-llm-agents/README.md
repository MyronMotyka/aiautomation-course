# 08. LLM API і AI-агенти

**Навіщо:** це ядро того, за що тобі платитимуть. Агент — це LLM, яка може викликати інструменти (CRM, календар, базу) і діяти за правилами бізнесу.

**Тривалість:** ~2–3 тижні

## Уроки
- [ ] Урок 1. Перший виклик LLM API: system prompt, messages, токени, вартість
- [ ] Урок 2. Structured output: змушуємо модель відповідати строгим JSON
- [ ] Урок 3. Промпти для бізнесу: роль, правила, приклади, «чого не робити»
- [ ] Урок 4. Tool use: агент викликає твої функції (перевірити слот, створити заявку)
- [ ] Урок 5. Пам'ять і контекст розмови
- [ ] Урок 6. Human-in-the-loop: агент готує чернетку, людина підтверджує
- [ ] Урок 7. Оцінка якості: тестовий набір питань, логування, метрики
- [ ] Урок 8. Вартість і надійність: вибір моделі, кешування, ліміти, fallback
- [ ] Підсумковий проєкт

## Підсумковий проєкт
Агент-адміністратор для умовної клініки: відповідає на питання, перевіряє вільні слоти (інструмент), створює запис (інструмент) і передає складні випадки людині. Плюс набір із 20 тестових діалогів для перевірки якості.

## Результат теми
Ти можеш зібрати агента, якому бізнес довірить спілкування з клієнтами, і довести, що він працює.
