# 11. Портфоліо: 3 демо-кейси

**Навіщо:** клієнт купує не «знання n8n», а результат, який бачить. Відео на 2 хвилини продає краще, ніж будь-яке резюме.

**Тривалість:** ~3–4 тижні (збирається з проєктів попередніх тем)

## Уроки
- [ ] Урок 1. Вибір кейсів під нішу і шаблон опису кейсу
- [ ] Урок 2. Кейс 1: AI-асистент з базою знань і записом на прийом
- [ ] Урок 3. Кейс 2: обробка заявок (форма → AI → CRM → менеджер)
- [ ] Урок 4. Кейс 3: документи і звіти (PDF/рахунки → таблиця → звіт)
- [ ] Урок 5. Запис демо-відео: сценарій, екран, озвучка
- [ ] Урок 6. Сторінка-портфоліо: сайт або Notion, кейси, контакти
- [ ] Підсумковий проєкт

## Підсумковий проєкт
3 кейси з відео, описом «проблема → рішення → результат у цифрах» і сторінкою, яку можна надіслати потенційному клієнту.

## Результат теми
Тобі є що показати на першій зустрічі.
