# AI Automation Learning

Мета: за ~3 місяці вийти на перші платні замовлення: агенти, інтеграції, автоматизація процесів для бізнесу.

Принцип: **код пише Claude Code, а ти проєктуєш, з'єднуєш системи, перевіряєш і продаєш.** Вчимо концепції та практику, а не синтаксис заради синтаксису.

## Як вчитися

1. Відкрий цю папку в Claude (вкладка Code → вибрати папку `AI-Automation-Learning`).
2. Напиши команду:
   - `/learn`: показати прогрес по всіх темах і що вчити далі;
   - `/learn sql` (або `python`, `n8n`, `api`, `agents`...): продовжити тему з того місця, де зупинився.
3. Claude веде урок крок за кроком: мета → теорія → приклади → практика → 5 контрольних запитань.
4. Урок зараховується, якщо 4 з 5 відповідей правильні. Прогрес і нотатки зберігаються в `README.md` кожної теми (розділ «Журнал навчання»).

Можна перемикатися між темами: пройшов 2 уроки SQL, потім 3 уроки n8n, потім повернувся до SQL. Кожна тема пам'ятає, де ти зупинився.

Перший урок кожної теми вже написаний. Наступні Claude створює, коли ти до них доходиш, за планом теми. Так уроки виходять актуальними і не витрачають ліміти наперед.

## Чого НЕ вивчаємо (свідомо)
- Глибокий Python: алгоритми, теорію ООП, LeetCode.
- Make і Zapier паралельно з n8n.
- Навчання ML-моделей і математику AI.
- Kubernetes і складний DevOps.
- Глибоко LangChain: прямі API-виклики простіші й надійніші.
