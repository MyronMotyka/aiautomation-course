# 06. Docker і VPS

**Навіщо:** self-hosted n8n і твої Python-сервіси мають десь жити. Docker дає змогу розгорнути все однаково на будь-якому сервері й оновлювати без болю.

**Тривалість:** ~1–2 тижні

## Уроки
- [ ] Урок 1. Що таке Docker: образ, контейнер, volume. Перший запуск n8n у Docker
- [ ] Урок 2. docker compose: n8n + Postgres разом
- [ ] Урок 3. VPS: SSH-ключі, firewall, оновлення системи
- [ ] Урок 4. Домен і HTTPS: reverse proxy (Caddy або Nginx)
- [ ] Урок 5. Бекапи та оновлення n8n без втрати даних
- [ ] Урок 6. Логи і діагностика: docker logs, місце на диску, пам'ять
- [ ] Підсумковий проєкт

## Підсумковий проєкт
n8n + Postgres на VPS через docker compose, з доменом і HTTPS, автоматичним щоденним бекапом і інструкцією «як відновити все з нуля».

## Результат теми
Ти можеш за годину розгорнути клієнту власний сервер автоматизацій.
