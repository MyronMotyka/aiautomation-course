# 09. RAG: агент відповідає з документів клієнта

**Навіщо:** «бот, який знає все про нашу компанію» — найпопулярніший запит від бізнесу. Прайси, FAQ, інструкції, договори.

**Тривалість:** ~1–2 тижні

## Уроки
- [ ] Урок 1. Що таке RAG і коли він взагалі потрібен
- [ ] Урок 2. Embeddings і векторний пошук на пальцях
- [ ] Урок 3. Підготовка документів: чанкінг, очищення, метадані
- [ ] Урок 4. RAG у n8n + Supabase pgvector
- [ ] Урок 5. Якість: перевірка відповідей, посилання на джерело, «не знаю», коли інформації немає
- [ ] Урок 6. Оновлення бази знань: клієнт змінив прайс, і що далі
- [ ] Підсумковий проєкт

## Підсумковий проєкт
Асистент, який відповідає з 10–20 документів реального або вигаданого бізнесу, вказує джерело і чесно каже «не знаю», якщо відповіді в документах немає.

## Результат теми
Ти продаєш «бота з базою знань» і знаєш, як зробити, щоб він не вигадував.
