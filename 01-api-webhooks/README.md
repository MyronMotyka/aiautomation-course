# 01. API, HTTP і webhooks

**Навіщо:** кожна автоматизація — це системи, що спілкуються через API. Хто розуміє API, той лагодить те, що «чомусь не працює» в n8n.

**Тривалість:** ~2 тижні

## Уроки
- [ ] Урок 1. Як працює HTTP: запит, відповідь, методи, статус-коди
- [ ] Урок 2. REST API на практиці: читаємо документацію, Postman/curl
- [ ] Урок 3. Авторизація: API-ключі, Bearer-токени, Basic Auth
- [ ] Урок 4. OAuth2: як працює «Увійти через Google» і чому токени протухають
- [ ] Урок 5. Webhooks: приймаємо події від інших сервісів, перевірка підпису
- [ ] Урок 6. Пагінація, ліміти запитів (429), повтори (retry)
- [ ] Підсумковий проєкт

## Підсумковий проєкт
Python-скрипт або n8n-workflow, який:
1. Забирає дані з публічного API з пагінацією (усі сторінки, а не лише першу).
2. Правильно обробляє помилки 429 і 5xx: чекає і повторює.
3. Зберігає результат у файл або таблицю.

## Результат теми
Ти можеш відкрити документацію будь-якого API і за 30 хвилин зробити до нього робочий запит.
