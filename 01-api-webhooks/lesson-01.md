# Урок 1. Як працює HTTP: запит, відповідь, методи, статус-коди

## Мета

## Теорія

### 1. Запит і відповідь
Кожна взаємодія через API складається з **запиту** (request) і **відповіді** (response).

Запит містить:
- **метод**: що хочемо зробити;
- **URL**: куди звертаємось (`https://api.site.com/v1/clients?page=2`);
- **заголовки (headers)**: службова інформація, наприклад ключ доступу чи формат даних;
- **тіло (body)**: дані, які надсилаємо (зазвичай JSON).

Відповідь містить **статус-код**, заголовки і тіло з даними.

### 2. Методи
| Метод | Що робить | Приклад у бізнесі |
|---|---|---|
| GET | Отримати дані | Список заявок з CRM |
| POST | Створити | Нова заявка |
| PUT / PATCH | Оновити (повністю / частково) | Змінити статус угоди |
| DELETE | Видалити | Видалити дублікат контакту |

### 3. Статус-коди: головна підказка при дебагу
| Код | Значення | Що робити |
|---|---|---|
| 200, 201 | Успіх (201 — створено) | Все добре |
| 400 | Неправильний запит | Перевір тіло: формат JSON, обов'язкові поля |
| 401 | Не авторизований | Ключ неправильний або протух |
| 403 | Заборонено | Ключ правильний, але немає прав |
| 404 | Не знайдено | Помилка в URL або ID |
| 429 | Забагато запитів | Почекай і повтори (ліміти API) |
| 500–504 | Проблема на сервері сервісу | Не твоя вина. Повтори пізніше |

**Правило:** 4xx — проблема у твоєму запиті, 5xx — у них на сервері.

## Приклади

Безкоштовне тестове API без ключа: `https://jsonplaceholder.typicode.com`.

PowerShell (у Windows пиши саме `curl.exe`, бо просто `curl` — це інша команда):
```powershell
curl.exe -i https://jsonplaceholder.typicode.com/users/1
```
Прапорець `-i` показує статус і заголовки. Зверни увагу на `HTTP/1.1 200 OK` і `Content-Type: application/json`.

Python:
```python
import requests

r = requests.get("https://jsonplaceholder.typicode.com/users/1", timeout=10)
print(r.status_code)          # 200
print(r.headers["Content-Type"])
print(r.json()["email"])

new = requests.post(
    "https://jsonplaceholder.typicode.com/posts",
    json={"title": "Нова заявка", "body": "Клієнт хоче консультацію", "userId": 1},
    timeout=10,
)
print(new.status_code, new.json())  # 201 і створений об'єкт з id
```
